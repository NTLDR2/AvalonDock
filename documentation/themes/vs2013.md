# VS2013 Theme (`Type2Hybrid`)

`Dirkster.AvalonDock.Themes.Type2Hybrid` (`AvalonDock.Themes.Type2Hybrid`) provides the flat, crisp Visual Studio 2013 aesthetic in **Dark**, **Light**, and **Blue** palettes, targeting `.NET Framework 4.8` (`net48`) exclusively with zero external NuGet dependencies. All three variants inherit directly from `DictionaryTheme` and construct frozen `SolidColorBrush` dictionaries at runtime from embedded, GZIP-compressed `.vstheme.gz` resources (`#572`), eliminating thousands of lines of duplicated XAML brush dictionaries while preserving exact VS2013 control templates and docking indicators.

dotnet add package Dirkster.AvalonDock.Themes.Type2Hybrid

## Usage

### XAML

```xml
<Window x:Class="MyApp.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        xmlns:avalonDock="https://github.com/NTLDR2/AvalonDock">

    <avalonDock:DockingManager x:Name="dockManager">
        <avalonDock:DockingManager.Theme>
            <avalonDock:Vs2013DarkTheme />
            <!-- Or: <avalonDock:Vs2013LightTheme /> -->
            <!-- Or: <avalonDock:Vs2013BlueTheme /> -->
        </avalonDock:DockingManager.Theme>

        <!-- Layout -->
    </avalonDock:DockingManager>
</Window>
```

### Code-Behind

```csharp
using AvalonDock.Themes.Type2Hybrid;

dockManager.Theme = new Vs2013DarkTheme();
dockManager.Theme = new Vs2013LightTheme();
dockManager.Theme = new Vs2013BlueTheme();
```

## v5 Architecture & Migration Note

{: .warning }
In AvalonDock v4, `AvalonDock.Themes.VS2013` shipped loose XAML files such as `DarkBrushs.xaml`, `LightBrushs.xaml`, `BlueBrushs.xaml`, and `DarkTheme.xaml`. Those XAML files were **removed in v5** (`#572`) when the package moved to embedded `.vstheme.gz` resources (`vs2013dark.vstheme.gz`, `vs2013light.vstheme.gz`, `vs2013blue.vstheme.gz`), and in **`NTLDR2 Fork v5.1.0`** the assembly and CLR namespace are renamed to **`AvalonDock.Themes.Type2Hybrid`**. Any v4 custom theme attempting to merge removed `VS2013` XAML brush dictionaries will throw `IOException` at runtime.

The compiled XAML dictionaries inside `AvalonDock.Themes.Type2Hybrid` are:

- `/AvalonDock.Themes.Type2Hybrid;component/Themes/Generic.xaml` — VS2013 control templates (merging `OverlayButtons.xaml`, `Themes/Menu/MenuItem.xaml`, and `Themes/Icons/IconGeometry.xaml`)

*(Note: the internal palette loader classes `VsThemeResources` and `VsThemePaletteFactory` inside `AvalonDock.Themes.Type2Hybrid` are `internal` implementation details and are not part of the public API.)*

## Customizing VS2013 Brushes at Runtime

Because `Vs2013DarkTheme`, `Vs2013LightTheme`, and `Vs2013BlueTheme` inherit from `DictionaryTheme`, each instance exposes its pre-populated `ThemeResourceDictionary` publicly (with all default `SolidColorBrush` entries pre-frozen). You can override any `AvalonDock.Themes.Type2Hybrid.Themes.ResourceKeys` brush before assigning the theme to `DockingManager.Theme`:

```csharp
using System.Windows.Media;
using AvalonDock.Themes.Type2Hybrid;
using Vs2013Keys = AvalonDock.Themes.Type2Hybrid.Themes.ResourceKeys;

var theme = new Vs2013DarkTheme();

var customAccent = new SolidColorBrush(Color.FromRgb(0xE0, 0x6C, 0x75));
customAccent.Freeze();

theme.ThemeResourceDictionary[Vs2013Keys.ControlAccentBrushKey] = customAccent;
theme.ThemeResourceDictionary[Vs2013Keys.DocumentWellTabSelectedActiveBackground] = customAccent;
theme.ThemeResourceDictionary[Vs2013Keys.ToolWindowCaptionActiveBackground] = customAccent;

dockManager.Theme = theme;
```

For full `.vstheme` or JSON palette customization, see [VS Theme]({{ site.baseurl }}{% link themes/vs.md %}), or see [Custom Themes]({{ site.baseurl }}{% link guides/custom-themes.md %}) for custom `Theme` and `DictionaryTheme` subclasses.
