# VS2010 Theme

`Dirkster.AvalonDock.Themes.VS2010` reproduces the classic Visual Studio 2010 docking appearance with textured blue-gray workspace backgrounds, warm gold active document tabs and tool window captions, rounded pane frames, and full `IconSource` rendering on document and tool window tabs.

---

## Installation

```bash
dotnet add package Dirkster.AvalonDock.Themes.VS2010
```

| Property | Value |
|:---------|:------|
| **NuGet Package** | `Dirkster.AvalonDock.Themes.VS2010` |
| **Assembly** | `AvalonDock.Themes.VS2010` |
| **CLR Namespace** | `AvalonDock.Themes` |
| **Theme Class** | `VS2010Theme` *(note uppercase `VS`)* |
| **Document Tab Icons** | Supported (`IconSource` displayed directly in tab headers) |

---

## Usage

### XAML

```xml
<Window x:Class="MyApp.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        xmlns:avalonDock="https://github.com/Dirkster99/AvalonDock"
        xmlns:vs2010="clr-namespace:AvalonDock.Themes;assembly=AvalonDock.Themes.VS2010">

    <avalonDock:DockingManager x:Name="dockManager">
        <avalonDock:DockingManager.Theme>
            <vs2010:VS2010Theme />
        </avalonDock:DockingManager.Theme>

        <!-- Layout -->
    </avalonDock:DockingManager>
</Window>
```

### Code-Behind

```csharp
using AvalonDock.Themes;

dockManager.Theme = new VS2010Theme();
```

## Pack URIs & Brush Customization

`VS2010Theme` is a URI-based `Theme` backed by compiled XAML dictionaries:

| Pack URI | Description |
|:---------|:------------|
| `/AvalonDock.Themes.VS2010;component/Theme.xaml` | Complete VS2010 theme dictionary returned by `VS2010Theme.GetResourceUri()` |
| `/AvalonDock.Themes.VS2010;component/Brushes.xaml` | Textured `DrawingBrush`, `LinearGradientBrush`, and `SolidColorBrush` resources (`AvalonDock_ThemeVS2010_BaseColor1`, etc.) |

To customize specific brushes while keeping the VS2010 chrome and tab icons, merge `/AvalonDock.Themes.VS2010;component/Theme.xaml` into your own `ResourceDictionary` and redefine the desired `AvalonDock_ThemeVS2010_BaseColor*` string keys.
