# VS2010 Theme (`Type1Legacy`)

`VS2010Theme` (shipped in `Dirkster.AvalonDock.Themes.Type1Legacy`) reproduces the classic Visual Studio 2010 docking appearance with textured blue-gray workspace backgrounds, warm gold active document tabs and tool window captions, rounded pane frames, and full `IconSource` rendering on document and tool window tabs.

---

## Installation

```bash
dotnet add package Dirkster.AvalonDock.Themes.Type1Legacy
```

| Property | Value |
|:---------|:------|
| **NuGet Package** | `Dirkster.AvalonDock.Themes.Type1Legacy` |
| **Assembly** | `AvalonDock.Themes.Type1Legacy` |
| **CLR Namespace** | `AvalonDock.Themes.Type1Legacy` |
| **Theme Class** | `VS2010Theme` *(note uppercase `VS`)* |
| **Document Tab Icons** | Supported (`IconSource` displayed directly in tab headers) |

## Usage

### XAML

```xml
<Window x:Class="MyApp.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        xmlns:avalonDock="https://github.com/NTLDR2/AvalonDock">

    <avalonDock:DockingManager x:Name="dockManager">
        <avalonDock:DockingManager.Theme>
            <avalonDock:VS2010Theme />
        </avalonDock:DockingManager.Theme>

        <!-- Layout -->
    </avalonDock:DockingManager>
</Window>
```

### Code-Behind

```csharp
using AvalonDock.Themes.Type1Legacy;

dockManager.Theme = new VS2010Theme();
```

## Pack URIs & Brush Customization

`VS2010Theme` is a URI-based `Theme` backed by compiled XAML dictionaries inside `AvalonDock.Themes.Type1Legacy`:

| Pack URI | Description |
|:---------|:------------|
| `/AvalonDock.Themes.Type1Legacy;component/Themes/VS2010/Theme.xaml` | Complete VS2010 theme dictionary returned by `VS2010Theme.GetResourceUri()` |
| `/AvalonDock.Themes.Type1Legacy;component/Themes/VS2010/Brushes.xaml` | Textured `DrawingBrush`, `LinearGradientBrush`, and `SolidColorBrush` resources (`AvalonDock_ThemeVS2010_BaseColor1`, etc.) |

To customize specific brushes while keeping the VS2010 chrome and tab icons, merge `/AvalonDock.Themes.Type1Legacy;component/Themes/VS2010/Theme.xaml` into your own `ResourceDictionary` and redefine the desired `AvalonDock_ThemeVS2010_BaseColor*` string keys.
